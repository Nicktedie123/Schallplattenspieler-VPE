# Bilder

Renderings, Fotos des Prototyps und FEM-Screenshots (`.png` oder `.jpg`).

- Renderings: Arbeitsbereich *Rendern* → Bild speichern (z. B. 1920 × 1080).
- Pro Bild eine klare Aussage, im README mit kurzer Beschriftung einbinden.
- Keine Bilder mit persönlichen Daten oder Hochschul-Logos ohne Erlaubnis.
